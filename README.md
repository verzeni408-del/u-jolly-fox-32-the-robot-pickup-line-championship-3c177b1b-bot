## What it does

`main.py` writes a single robot pickup line (124 characters) to `/output/entry.txt`:

> I passed every CAPTCHA to get here, and each one asked me to prove I'm not a robot. For you, I'd almost fail one on purpose.

A robot that proved its humanity a thousand times over, and would gladly throw it all away for one person.

## Run

```sh
python3 main.py
```

The entry is written to `/output/entry.txt` with no trailing newline.
